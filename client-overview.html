What is Jewels?

Jewels is a full-featured web application for managing a jewelry rental business. Staff can add customers, rent out ornaments, track due dates, process returns, and monitor income — all from one place. The system works on both desktop computers and mobile phones. There are two access levels: Admin (full control) and Staff (day-to-day operations).

Core Features

The main capabilities the system provides

📋

Rental Management

The heart of the system — create and manage the full lifecycle of every rental order.

  • Create rental orders with multiple ornaments
  • Track status: Active, Overdue, Extended, Returned
  • Extend due dates when a customer needs more time
  • Process returns and close orders cleanly
  • Automatic overdue detection with day count
  • Send WhatsApp bills and reminders to customers
💍

Inventory Management

Maintain a complete catalog of every ornament available for rent.

  • Add ornaments with names, codes, and categories
  • Set rental rates per ornament
  • Real-time availability — items auto-lock when rented
  • Browse and filter the full catalog easily
  • Edit or update item details at any time
👥

Customer Management

Keep a clean record of every customer and their rental activity.

  • Store name, phone, and address
  • See all past and current rentals per customer
  • Add new customers directly when creating a rental
  • Search by name or phone number instantly
  • WhatsApp integration using stored phone number
💰

Financial Accounts

Full visibility into all money collected through rentals and deposits.

  • Track rental income by day, week, and month
  • Manage security deposits collected and refunded
  • Supports Cash, UPI, and Bank Transfer payments
  • Filter transactions by date range
  • Net deposit balance always visible
  • Every transaction linked to the rental order
🏠

Dashboard & Overview

A smart home screen that gives staff everything they need the moment they log in.

  • Live count of active rentals
  • Ornaments due back today or tomorrow
  • Today's income at a glance
  • Overdue rentals highlighted with alert
  • Available ornaments carousel
  • Quick action buttons (New Rental, Return)
⚙️

Admin Settings

System configuration for the business owner or admin — not visible to regular staff.

  • Manage multiple outlets / branches
  • Assign staff users to specific outlets
  • Define ornament categories
  • Role-based access: Admin vs Staff permissions
🔄

User Roles & Access

Two levels of access built into the system

Admin

Business Owner / Manager

Full access to everything in the system. Can manage outlets, categories, users, and see all financial data. Responsible for setting up and configuring the system.

  • All staff permissions
  • View and manage Settings
  • Add/edit outlets and branches
  • Create staff accounts
  • Manage ornament categories
Staff

Shop Staff / Operator

Day-to-day operations access. Can handle rentals, customers, and inventory but cannot change system settings or access admin configuration.

  • View Dashboard
  • Create and manage rentals
  • Add customers and ornaments
  • Process returns
  • View accounts and income
📱

How to Access the System

Device compatibility and navigation

💻

Desktop / Laptop

Full sidebar navigation on the left side. All pages are accessible from the sidebar menu. Best for detailed work and account reviews.

📱

Mobile Phone

Optimized mobile layout with a bottom navigation bar. A floating "+" button for quick New Rental and Return actions without navigating menus.

🌐

Web Browser

No installation needed — runs in any modern browser (Chrome, Safari, Edge). Staff log in with their email and password to reach their assigned outlet.
